## Neighbor interpretability

Looking at the command-alias cohesion table in `summary.md` — do the
groups with a large intra/cross gap actually feel more "the same command"
than the ones with a small gap? Is there a command whose aliases *don't*

## Paraphrase vs. antonym separation

Do the antonym pairs actually score meaningfully lower than the
paraphrase pairs, or do some antonym pairs score close to (or above) some
paraphrase pairs? If the latter — is that a real limitation worth noting
before any future semantic command-matching path gets built on this
embedding space?

`trajectory_aasm-stage-transitions.png` — does the step-to-step
similarity move smoothly, or does one step jump/dip in a way that doesn't
match the phrases involved? Remember the spatial path itself is
decorative (random projection) — the step-similarity subplot is the
actual signal, not the zig-zagging line.
